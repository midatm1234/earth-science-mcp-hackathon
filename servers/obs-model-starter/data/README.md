## Provenance

- **Generated by** [scripts/generate_sample_data.py](../../../scripts/generate_sample_data.py) with fixed seed `20261030` on 2026-10-30.
- **Method**: a sinusoidal seasonal cycle per site plus Gaussian noise; model runs add a fixed per-site bias and extra noise. Model A is written in kelvin with mid-month time stamps to exercise unit conversion and time alignment.
- **Deliberate defects** for teaching missing-data rules:
  - `SYN-VALLEY` 2020-07 observation value is empty.
  - `SYN-COAST` 2021-02 observation has `qc_flag=suspect`.
  - `SYN-MOUNTAIN` 2020-12 observation row is absent.
  - `SYN-MOUNTAIN` 2021-11 model A value is the fill value `-9999`.
- **Reproducibility check**: `uv run python scripts/generate_sample_data.py --check` exits 0 only if these files match the generator byte for byte. The test suite runs this check.
- **Site coordinates** are illustrative locations in California. The values attached to them are not measurements from those places.

## Redistribution

The synthetic values are dedicated to the public domain under **CC0-1.0**. They may be copied into contributions, slides and offline bundles without attribution. Do not present them as observations or model output.
