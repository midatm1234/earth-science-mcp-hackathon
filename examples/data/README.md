# Example data

Index of every data file in the repository and its class. Never present synthetic or cached values as current observations.

| File | Class | Size | Source and date | Use |
|---|---|---|---|---|
| [servers/obs-model-starter/data/*.csv](../../servers/obs-model-starter/data/README.md) | **synthetic** | ~8 KB | Generated by `scripts/generate_sample_data.py`, seed 20261030, 2026-10-30 | Starter server fixtures; CC0-1.0 |
| [cached/earthdata_discovery_merra2_t2m.json](cached/earthdata_discovery_merra2_t2m.json) | **cached live response** | ~8 KB | Live call to `https://cmr.earthdata.nasa.gov/mcp/v1` on 2026-10-31T04:18:59Z (UTC) by `scripts/earthdata_probe.py` | Offline practice for tutorial 01; reading discovery results |

## Classes

| Class | Meaning | Rule |
|---|---|---|
| synthetic | Invented values | Label as synthetic in every output |
| cached live response | Saved output of a real service call | Show the retrieval date; re-run live before relying on it |
| recorded demonstration | Transcript of a past agent session | Label as a replay with its date |
| live call | Made now against a real service | Record date, endpoint, arguments |

## Regenerating

```bash
uv run python scripts/generate_sample_data.py --check     # verify fixtures
uv run python scripts/earthdata_probe.py --short-name M2TMNXSLV \
  --wkt "POLYGON((-121 33,-117 33,-117 38,-121 38,-121 33))" --start 2020-01-01 --end 2020-12-31 \
  --variable T2M --save examples/data/cached/earthdata_discovery_merra2_t2m.json   # refresh the cached example (network)
```

The cached file contains NASA CMR metadata. Cite the dataset by its DOI (MERRA-2 M2TMNXSLV: 10.5067/AP1B0BA5PD2K).
