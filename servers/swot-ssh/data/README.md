# Data card: swot-ssh

The server bundles no SWOT data. The test files are:

| File | What it contains | Units | Class | Source | License |
|---|---|---|---|---|---|
| `tests/data/cmr_swot_passes.json` | Four real CMR granule records (Basic passes over the California coast, 2026-11-04 to 06): name, times, size, archive link | none | cached live response | `https://cmr.earthdata.nasa.gov/search/granules.json?collection_concept_id=C3233945000-POCLOUD&bounding_box=-128,32,-117,42` | NASA open metadata |
| `tests/make_sample.py` (builds a file at test time) | A tiny NetCDF file in SWOT Basic layout: 2 swaths x 4 x 3 pixels, with one fill value and one flagged point | m | synthetic | generated by the script, values invented | CC0-1.0 |

## Provenance

- The CMR file was retrieved from the public CMR search API on 2026-11-12 with no login.
- The synthetic NetCDF values are invented for testing and are **not SWOT measurements**.
- Downloaded SWOT passes are never stored in the repository: they go to `swot_output/` (git-ignored) and the full pass is deleted after the region is saved.

## Redistribution

The CMR file contains only catalog metadata published openly by NASA. The synthetic file is generated, so nothing is redistributed.
